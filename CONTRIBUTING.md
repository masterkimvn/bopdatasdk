# Contributing

Open an issue to discuss changes, then submit a pull request with a clear description and appropriate tests. Run the checks in the CI workflow locally when possible. Use synthetic data in tests and respect dataset licenses. Keep clients read-only and preserve unknown API fields.


## Versioned source releases

The repository tracks public GitHub source releases in [CHANGELOG.md](CHANGELOG.md) and [docs/releases/](docs/releases/). Package registry publication, package identities, and license decisions are separate. Please do not create tags, GitHub releases, or publish packages without project-owner authorization. Keep examples useful for developers and AI agents, and ensure docs do not promise unsupported runtime capabilities.
