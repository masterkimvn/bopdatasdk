# BOP Data SDK for Go

Go module for [BOP Data](https://data.bop.ink): `github.com/masterkimvn/bopdatasdk/packages/go`.

After the nested module tag `packages/go/v1.0.0` exists and is verified:
```bash
go get github.com/masterkimvn/bopdatasdk/packages/go@v1.0.0
```

Use `NewClient`, `ListDatasets(ctx)`, `GetDataset(ctx,id)`, `GetDatasetCSV(ctx,id)`. The existing root GitHub tag v1.0.0 does not publish this nested module. SDK code MIT; data terms separate. Please acknowledge **BOP Data**.
