# BOP Data SDK for Swift

Read-only Swift client for [BOP Data](https://data.bop.ink). Add `packages/swift` as a local package in Xcode. A dedicated Swift Package Manager public mirror with Package.swift at repository root is needed for convenient remote dependencies and is not yet published.

Module: `BopData`. APIs: `listDatasets()`, `getDataset(_ id:)`, `getDatasetCSV(_ id:)`. Please credit **BOP Data**; datasets are outside the SDK MIT license.
