# BOP Data SDK v1.0.0 — First GitHub source release

**Release date:** October 28, 2026  
**Repository:** [masterkimvn/bopdatasdk](https://github.com/masterkimvn/bopdatasdk)  
**Data source:** [BOP Data](https://data.bop.ink)

This is the first versioned **source-code release** of BOP Data SDK: lightweight read-only clients for retrieving real public structured datasets from `data.bop.ink`.

## Included

- **11 SDK clients:** JavaScript/TypeScript, Python, PHP, Go, Java, C#/.NET, Rust, Ruby, Kotlin, Swift, and Dart.
- Dataset discovery via `/api/v1/datasets.json`.
- Dataset JSON and CSV retrieval by `canonicalId`.
- Consumer examples across languages, web frameworks, and mobile environments.
- Public developer documentation, AI agent integration instructions, and CI tests.

## Quick start

```bash
git clone --branch v1.0.0 --depth 1 https://github.com/masterkimvn/bopdatasdk.git
cd bopdatasdk
node examples/javascript-node/main.js
```

Or use the API directly:

```bash
curl -fsS https://data.bop.ink/api/v1/datasets.json
```

See [README](../../README.md), [all clients](../clients.md), [examples](../examples.md), and [AI agent guidance](../../AGENTS.md).

## What v1.0.0 means

This is a **stable, versioned GitHub source snapshot**, not publication of packages to npm, PyPI, Packagist, Maven Central, NuGet, crates.io, RubyGems, or pub.dev. Client package manifests may still use local/development versions such as `0.1.0`. No package registry publishing is included.

The SDK source license remains **unfinalized**; a public GitHub repository or release alone is not a permissive reuse license. Individual datasets retain their own terms, which are separate from the SDK source code.

## Known constraints

- Browser-only integrations rely on the upstream BOP Data CORS policy, which may restrict third-party origins.
- Native Android/iOS example apps were not built and tested on devices or simulators at handoff; React Native device compatibility is unverified.
- This SDK is only a bridge to BOP Data; it does not verify dataset facts, mirror the data, or run the backend.

## About BOP Data

[BOP Data](https://data.bop.ink) is a **public, non-profit, ad-free structured dataset initiative**. It is the data source, and this SDK is an integration layer for websites, apps, software, and AI.

Please acknowledge the source as **BOP Data** when using its datasets. A backlink is welcome, but not required for this simple acknowledgement; individual datasets may impose additional terms.
