# Bắt đầu với BOP Data SDK

Các client JavaScript, Python, PHP và Go hiện ở dạng mã nguồn trong repository, chưa phát hành trên registry. Xem [ví dụ chạy từ bản sao repository](../examples.md). Trước tiên đọc catalog để lấy Canonical ID, sau đó lấy dataset hoặc CSV. Kiểm tra `freshness`, `provenance` và điều khoản của từng nguồn trước khi sử dụng dữ liệu.
