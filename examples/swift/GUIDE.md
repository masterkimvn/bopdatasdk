# SwiftUI example

Create an iOS App project in Xcode with iOS 15 or later. Add `packages/swift` from this checkout as a local package, add `DatasetView.swift` and replace the generated app entry with `BopDataDemoApp.swift`. The view fetches the catalog and first dataset, then displays data, freshness and provenance, with loading and error states.

The Swift client has been tested on Linux and its macOS CI test has passed. This app has not been built or run on an iOS simulator or device.
